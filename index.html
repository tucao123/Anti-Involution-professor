        大学生和初入职场的人面对的不是「不够努力」，而是信息不对称：简历石沉大海、面试屡战屡败、不知道该把时间投在哪里。「职引者」把招聘数据、技能本体和可控的 AI 流程接成一条闭环，让下一步变得具体。

        ▣ 关于「被替代风险指数」的边界声明

        SAFI（Skill Automation Feasibility Index）基于 O*NET 的 35 项技能分类，衡量的是各项技能在文本任务层面的自动化可行性，不等于岗位整体可被替代。系统因此呈现四象限而非单一分数，并始终配套「可行动项」。我们不制造焦虑，也不对任何人的职业前景下判决。

        数据来源与边界声明

        DATA SOURCES

        当前版本把行业洞察严格拆成两个模式。「技能词频参考」接入无需登录态的公开岗位 API（Jobicy 主路径 / RemoteOK 兜底），样本量、技能出现率、低风险占比与综合评分全部由服务端确定性统计并标注来源与抓取时间；该样本是全球远程岗位，不代表中国境内招聘市场，也不是同比数据，趋势只在真实快照累积到 2 个点之后绘制，不做插值或编造。「国内市场洞察」需要 A 级商务授权数据，目前待授权，界面不展示任何数值、图表或排序，也绝不拿海外样本或演示集顶替。境内招聘平台无公开 API，技术文档 v1.3 已将隐身浏览器、登录态复用与规避技术措施的截图变体标注为「永久禁止」；受控研究采集为「待法务书面结论、执行体仅限练习沙盒、生产采集未解锁」，工程侧由 sources.py 的 fail-closed 闸门拦截，并保留 robots / Crawl-delay 检查与合规留痕。「本项目仅用于研究与学习，不得用于任何商业行为」是全项目条款，不是合规豁免：PIPL 第 13 条未列举「研究 / 非商用」项，可争取的是第(六)项「合理范围内处理已合法公开的信息」，但附带的去标识化、最小留存与不对外分发条件反而更严格。

        能力对齐新增「用户自带 JD」（C 级）：粘贴你有权使用的目标岗位 JD，由确定性规则抽取必备 / 加分 / 隐含三级技能，可选项填简历要点后计算加权覆盖率与差距雷达。全文在抽取前自动脱敏手机号、邮箱、身份证号与联系人标签；原文零落盘、不外发云端模型，内存会话只保留脱敏后的结构化结果，服务重启即清空，也可随时撤回删除。本版本不提供匿名聚合，不会用于统计或模型训练；未填简历要点时不推断覆盖率，不编造分数。未连接本地服务时可在浏览器内做「本地预览」，文本不上传、不落盘、无服务端留痕。若调用语言模型给出准备建议，只发送技能名、级别与覆盖率等结构化字段，JD 原文与证据短句一律不外发。

        截图只是输入形态，不是合规豁免。系统不会自动打开招聘网站截图，也不提供定时或批量截图；采集设置集中在管理员视图，默认关闭、逐次手动开关，开关打开也不代表会发起第三方请求；把抓取 HTML 改成截图 + OCR 不改变自动化访问第三方页面的性质，若为绕过字体反爬或登录校验而截图，反而可能构成避开技术措施。唯一开放的截图路径是你自己手动截取、主动上传你有权查看的岗位 JD 或本人简历：图片仅以浏览器内存中的 blob 存在，本地 OCR 后用完即释放，不上传、不落盘、不发往云端模型或第三方识别服务；识别结果写进可编辑文本框，由你核对后才提交，提交时只发送文本并沿用上述全部 C 级控制点。截图结果不进入行业洞察，不产生任何市场级数值。

        本地研究检索索引把这条 C 级链路再往下延伸一步：已核对的文本经 PII 脱敏、分块、字符 n-gram 稀疏向量化后存入本机索引，可按技能词检索原文片段。服务端不接收截图位图 / 音频，位图自始不离开浏览器内存；B1 虽新增文件上传端点，但只收 pdf / docx 且在内存解析完即释放，不落盘、不入库。截图 / 爬取链路的隐私信息整行剔除、不入库，只保留岗位信息用于提供大致岗位信息；该链路不产出个人画像，个人画像由用户主动提供 JD / 简历的本地「能力对齐」链路提供。向量不等同于匿名化（存在反演风险），因此片段用 AES-256-GCM 加密落盘，默认 30 天留存、可按文档删除或整库清空，并全程写入审计哈希链；未配置持久密钥时服务重启即自动清空。每条检索结果都带数据分级与禁止结论，C / D 级片段不得据此推断国内就业形势、同比、薪资或蓝海岗位。研究用途不解锁国内市场洞察，也不改变上述任何采集红线。

        定向学习与面试评分的底表仍为内置演示数据集；公开数据源不可用时洞察页自动降级为演示集。检索已形成双链路：本地稀疏索引（字符 n-gram + 技能本体 TF-IDF，C 级用户数据专用、片段加密、可撤回删除）与 Qdrant 云向量库（只收 D 级公开岗位样本，BGE 语义向量未就绪时降级为确定性投影并如实标注）；LangGraph 编排、PostgreSQL / Redis / Neo4j、Celery 均以「可选依赖 + 本地降级」接入，任一服务缺失都不影响页面功能。简历 PII 的字段级加密、脱敏、一键删除与审计哈希链已在本地落地，B1 简历上传 / 解析已按项目所有者 2026-11-16 回执开放：仅 pdf / docx、纯内存解析、不留存、只输出大致岗位信息、不提取隐私信息、有撤回与删除入口；工程开关不等于法务书面结论（Q19 仍待回）。C 级原文仍零落盘、默认不出本机。语言模型层默认 qwen：凭据只由本地 BFF 在服务端持有，页面不接触任何密钥；未配置或未启用时自动降级为规则引擎，数值与流程始终走确定性管道，模型输出先经服务端校验。

        本地偏好

        LOCAL UI STATE

        为避免刷新后丢失进度，浏览器仅在本机保存非敏感界面状态：学习阶段勾选、当前视图、当前 JD 标签、面试语气模式。不保存 JD 原文、简历要点、OCR 文本、面试回答、面试报告与任何个人信息——这些内容仍只在内存中使用，刷新即清空，与上文 C 级链路的承诺一致。研究索引的留存由服务端单独控制，与此处的界面偏好无关。
